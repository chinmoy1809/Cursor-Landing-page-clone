# Cursor Landing Page Clone 

This project is a **frontend clone** of the Cursor AI landing page, recreated for learning and practice purposes.  
The goal was to improve layout skills, responsiveness, and modern UI recreation using web technologies.

---

## Sections Recreated

The following sections of the original Cursor landing page were recreated:

- **Navbar**
  - Logo
  - Navigation links
  - Call-to-action button

- **Hero Section**
  - Main headline
  - Supporting text
  - Primary action buttons
  - Background styling

- **Features Section**
  - Product feature highlights
  - Cards layout
  - Icons and descriptions

- **UI Showcase / Product Preview**
  - Visual representation of the product interface
  - Responsive alignment

- **Footer**
  - Navigation links
  - Branding
  - Minimal footer layout

---

## Fonts Used

The project uses modern sans-serif fonts similar to the original Cursor website:

- **Primary Font:** Inter
- **Fallback Fonts:** system-ui, sans-serif

These fonts help maintain a clean and developer-focused aesthetic.
